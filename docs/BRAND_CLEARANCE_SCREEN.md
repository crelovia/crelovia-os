# Crelovia OS — Preliminary name, domain and Fedora-brand screening

**Screen date:** 2026-11-03  
**Status:** OPEN — preliminary search only; **not** legal trademark clearance, a domain-availability certification, or release approval.

## Screening notes

- Public-web searches for `"Crelovia"`, `"Crelovia OS"`, Crelovia plus software/trademark, and likely domain strings did **not surface an obvious exact-match competing operating-system/software brand** among the returned results during this pass. A lack of indexed results cannot establish a lack of trademark or common-law rights.
- The USPTO's **official** trademark search portal was identified, but an authenticated/complete live search of marks and their records was **not completed** in this pass. Do not mark USPTO clearance done.
- The USPTO recommends examining **confusingly similar marks**, related goods/services, federal applications/registrations, state registrations, international sources, and actual marketplace use. Search exact spelling, similar pronunciations, misspellings and visual similarity; review goods and services for software (including potential International Class 9) and online software services (potential Class 42), without assuming classes alone settle confusion.
- `crelovia.com`, `crelovia.org`, `crelovia.net` have **not** been verified as registerable, registered, owned, or available. A search-result absence is not an RDAP result. Use ICANN Lookup / authoritative registrar and recheck at purchase.
- The existing `crelovia` GitHub organization is a project presence, **not** independent proof of trademark priority or domain control.
- No original Crelovia logo design was reviewed for potential third-party mark similarities.

## Fedora-based distribution considerations

Fedora's public remix guidance allows a downstream distribution to have a different name and original logos. **This does not authorize presenting a modified Crelovia image as an official Fedora distribution.** Fedora's trademark and redistribution guidelines must be checked before any public image/installer release, including Fedora-branded packages/artwork, Fedora release identity, and the conditions for use of the optional **Fedora Remix** marks.

The preliminary project architecture uses Fedora bootc and KDE; these software components retain their own copyright/license and trademark rules. Do not distribute the experimental image until relevant notice, source supply, trademark/branding and security gates have been reviewed.

## Open verification gates

- [ ] Personally inspect live USPTO Trademark Search results for exact and potentially confusingly similar marks; record search strings, result timestamps, serial numbers, owners, status and related goods/services. A legal professional should review material conflicts before public launch.
- [ ] Check state marks and internet/common-law use for software/OS/creator tools, and WIPO/EU/TMview sources as launch regions warrant.
- [ ] Run ICANN RDAP lookups plus registrar availability checks for preferred domains; document results and any purchased domains separately.
- [ ] Check social handles and likely impersonation/confusion issues, without assuming account availability grants brand rights.
- [ ] Audit actual Crelovia packages, splash/screens, desktop identity files, artwork, and docs against the current Fedora trademark policies before public distribution.
- [ ] Confirm Crelovia logo design is original and not confusingly similar to existing logos.
- [ ] Recheck results close to first public beta; consider appropriate attorney-reviewed comprehensive clearance.

**Roadmap decision:** Do **not** mark Milestone 0's "Validate name, domain, and trademark clearance" item complete on the basis of this screen.
