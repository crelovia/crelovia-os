# Crelovia OS — Project Charter

Status: Draft v0.1 | Established: 2026-10-22

## Vision
Crelovia OS is a community-developed, privacy-first desktop operating system for creators and everyday users. Its guiding statement is **Your world. Your way.**

## Audience
Video editors, musicians, artists, game developers, streamers (including dual-PC setups), and general desktop users.

## Principles
1. **User ownership:** no mandatory Crelovia account or advertising platform.
2. **Privacy by default:** minimize data collection, give clear controls, and do not claim that an OS can prevent all doxxing or harassment.
3. **Familiar and customizable:** approachable defaults with extensible themes, panels, shortcuts, workflows, and accessibility features.
4. **Creator-ready:** prioritize reliable audio, graphics, capture, encoding, and development workflows.
5. **Transparent compatibility:** publish tested hardware/software results; do not promise all Windows software works.
6. **Community stewardship:** public source, documented decisions, accessible contributions, and respectful governance.
7. **Reliability first:** reproducible builds, staged testing, recovery and rollback planning.

## Planned differentiators
- Creator workflow presets that remain optional.
- Community-published Workspace Packs with explicit permissions and safer import previews.
- Broadcast-safe workflows and manually triggered emergency scenes in compatible streaming tools.
- Clear security boundaries between creator, personal, and broadcast contexts. Layouts alone are not security isolation.
- User-controlled updates and recovery mechanisms.

## Non-goals for the first prototype
- A new kernel or Windows-compatible implementation from scratch.
- Guaranteed support for Adobe products, all capture hardware, anti-cheat, or proprietary audio plugins.
- Claims of certified anonymity, foolproof automatic secret detection, or production-grade security.

## Project status
The project is in planning. No installable Crelovia build or security audit exists yet. Branding and trademark clearance remain pending.

## Open decisions
- Select an image-based Fedora technology and toolchain based on tested upstream support.
- Review licenses for original code and all redistributed components.
- Decide maintainer governance and release signing/key custody.
- Define a supported hardware test matrix and threat model.
