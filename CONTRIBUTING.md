# Contributing to Crelovia OS

Thanks for your interest! Crelovia is an early-stage project. Documentation, research, reproducible testing, accessibility feedback, and verified compatibility reports are especially useful.

## Before contributing
- Read [Project Charter](docs/PROJECT_CHARTER.md), [Roadmap](docs/ROADMAP.md), and [Security Policy](SECURITY.md).
- Search existing issues or open a discussion before large changes.
- Explain your use case, expected behavior, testing, and compatibility impact.
- Never include secrets, personal data, telemetry dumps, or proprietary assets without permission.

## Pull requests
- Keep changes focused and describe how you tested them.
- Prefer upstream-compatible changes, declarative configuration, and reversible defaults.
- Document licensing and source provenance for added dependencies or graphics.
- Mark experiments clearly; do not advertise unverified privacy/security claims.
- Contributors must have rights to submit their contributions. No CLA has been adopted.

## Code of conduct
Be welcoming and constructive. Harassment, threats, doxxing, hate speech, and disclosure of private information are not acceptable. A formal reporting and escalation process will be established before broader community recruitment. Do not send private reports to a public issue.

## Licensing note
A license for original Crelovia files has not yet been selected. Until then, public visibility does not imply permission for reuse beyond applicable law. Please discuss substantial code contributions before submitting them.
